# Windows App Storage Inspector & Cleanup Plugin

Inspect Windows application storage, understand local disk usage, and safely move approved cleanup items to the Recycle Bin.

## Installation

```bash
copilot plugin install windows-app-storage-inspector-cleanup@plagueho-copilot
```

## Source

This plugin is part of [PlagueHO Copilot](https://github.com/PlagueHO/plagueho.copilot). It is also published to [Awesome Copilot](https://github.com/github/awesome-copilot) and can be installed from there.
